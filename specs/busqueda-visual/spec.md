# Visual search of sightings

Authenticated CIUDADANO uploads 1-5 JPEG/PNG/WebP photos (5 MiB each) and selects dog/cat species. Return up to five active sightings from active users, same species, ranked by visual similarity. This is candidate retrieval, not identity confirmation; no calibrated probability or rejection threshold. Query photos are not persisted. No Bedrock, payment, alert search or web UI in this delivery. Existing flows remain available if Python is down. No commits/push/APK.

Use downloaded pet-recognition-base ONNX on CPU, SHA256 pinned. Images should contain one clearly visible animal; no detector is included, document this limitation. Model supports dogs/cats according to its author; validate locally without promising field accuracy. Cache 512-dimensional normalized vectors by sighting photo and model version in PostgreSQL, FK cascade on photo deletion. Build missing entries on demand, including old sightings. Never index personal pet photographs or query photos. Limit candidate set to 200 sighting photos per selected species; reject 422 rather than silently truncating. Skip unavailable remote photos, disclose count, and fail 503 if all candidate photos fail. Do not invent results.
